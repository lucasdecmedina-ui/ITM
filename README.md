# Melody Stage

Crie um site completo para o Instituto Tinello de Música (ITM), escola de música localizada em Santos/SP.

A identidade visual deve seguir:

- Preto profundo como cor principal

- Amarelo vibrante/dourado como cor de destaque

- Branco para textos

- Estética moderna, premium e artística

O conceito visual é:

"Um palco moderno onde a música ganha vida."

A interface deve transmitir:

- paixão pela música

- evolução dos alunos

- profissionalismo

- ambiente acolhedor

- energia jovem

---

ESTRUTURA DO SITE:

1. HERO

Criar uma hero section de impacto ocupando a primeira tela.

Elementos:

- Fundo escuro cinematográfico

- Imagem ou vídeo relacionado à música

- Iluminação quente em tons amarelos/dourados

- Overlay preto para melhorar leitura

Adicionar animação de fundo com notas musicais flutuando.

IMPORTANTE:

As notas musicais devem ser:

- discretas

- elegantes

- com baixa opacidade

- movimento lento

- estilo partículas/luz de palco

- nunca parecer infantil ou exagerado

Criar sensação de que a música está presente no ambiente.

Texto:

Instituto Tinello de Música

"Sinta a Música. Viva sua Evolução."

Descrição:

Aprenda instrumentos, desenvolva seu talento e faça parte de uma comunidade apaixonada por música.

Botões:

- Agendar Aula

- Conhecer Cursos

2. SOBRE O ITM

Criar uma seção contando a história e filosofia da escola.

Adicionar um vídeo institucional fornecido.

REGRAS DO VÍDEO:

- O vídeo possui formato vertical 9:16 (celular)

- Deve ser exibido em formato retrato

- Deve ficar em loop automático infinito

- Deve iniciar automaticamente

- Deve ser SEM ÁUDIO (mutado)

- Não adicionar controles de vídeo visíveis

- Usar autoplay + muted + loop

O vídeo deve ficar integrado ao design, como uma peça visual da seção.

IMPORTANTE:

Todos os arquivos de mídia devem ficar dentro da estrutura do projeto.

Organizar imagens e vídeos em uma pasta de fácil acesso, por exemplo:

 /public/assets/

Não deixar arquivos hospedados externamente.

A intenção é permitir futuras alterações diretamente pelo GitHub.

MOTION DESIGN / ANIMAÇÕES PREMIUM

O site deve possuir animações modernas, elegantes e suaves.

A sensação deve ser:

"um palco ganhando vida lentamente."

Evitar animações exageradas ou chamativas.

Priorizar:

- fluidez

- profundidade

- iluminação

- movimento orgânico

====================================================

ANIMAÇÕES DE ENTRADA

Ao carregar a página:

Hero:

- título aparecendo com fade suave + pequeno movimento vertical

- descrição surgindo com atraso elegante

- botões entrando suavemente

- elementos de fundo com movimento lento

Durante o scroll:

Cada seção deve aparecer com:

- fade-in

- leve subida

- transição suave

Usar efeito de revelação conforme o usuário navega.

====================================================

EFEITOS DE HOVER

Botões:

Ao passar o mouse:

- brilho dourado suave

- leve expansão

- transição fluida

Exemplo:

Botão amarelo:

- aumenta levemente

- cria uma aura de luz ao redor

Cards de cursos:

Ao passar o mouse:

- card sobe alguns pixels

- borda dourada aparece

- imagem aproxima lentamente

- sombra aumenta

Fotos da galeria:

Hover:

- zoom cinematográfico lento

- overlay escuro aparece

- detalhe dourado surge

====================================================

EFEITOS DE FUNDO

Adicionar movimento sutil:

Notas musicais:

- flutuação lenta

- opacidade baixa

- movimento contínuo

Luzes:

Criar pequenos efeitos de iluminação:

- reflexos dourados

- glow suave

- partículas discretas

Adicionar sensação de iluminação de palco.

====================================================

EFEITO PARALLAX

Aplicar parallax leve em algumas imagens:

- fotos da escola

- instrumentos

- imagens de apresentações

O movimento deve ser discreto e premium.

====================================================

Criar interação nos cards:

Cards entram sequencialmente.

Exemplo:

Violão aparece primeiro.

Depois guitarra.

Depois bateria.

Com pequenos atrasos entre eles.

====================================================
